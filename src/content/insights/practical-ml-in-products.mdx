Adding machine learning to a product is less about the model and more about the data pipeline, the
integration point, and whether the output is actually useful to the person using it.

The interesting engineering problems in applied AI are rarely model architecture. They are data
ingestion from messy real-world sources, schema drift, evaluation without ground truth, and the
honest presentation of uncertainty to users who just want an answer.

## The pipeline is the product

A model output is only as trustworthy as the pipeline feeding it. Before any intelligence layer is
worth building, the data needs to be clean, structured and reliably collected. That work is less
glamorous than fine-tuning a model â€” and far more determinative of whether the product actually
helps.
